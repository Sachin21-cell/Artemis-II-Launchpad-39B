# Artemis-II-Launchpad-39B
The light-up desktop version!

I aim to achieve by using my electronics skills to apply the LEGO Artemis set lights to mine whilst using the lights with 3M tape to stick. If the user has not a plug near their setting (desk), they can simply use the battery box provided.

This was a huge and daunting project. Hope I can get the funding!
